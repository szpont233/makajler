IMPERIUMLECHITOW.PL
Jest to strona internetowa założona w celach humorystycznych i nie ma zamiaru nikogo obrazić. Informacje na niej nie powinny być brane na poważnie.



Alphanium AI
Jak z niego korzystać? Stwórz swój klucz API z https://aistudio.google.com/, wklej go tutaj i pisz!
Co z prywatnością moich danych? Ja waszych danych nie zbieram. A co Google z nimi robi dalej? Nie wiem, ale ja nie mam dostępu do waszych czatów ani kluczów API,
ponieważ wszystko jest zapisywane lokalnie. Jak usuniesz wszystkie pliki cookie, to wszystko co było zniknie.

Częste błędy

400 INVALID_ARGUMENT Nieprawidłowo sformatowane żądanie (błąd w nazwie pola, nieobsługiwany parametr lub niezgodna wersja API)
403 PERMISSION_DENIED Błędny lub wygasły klucz API. Wygeneruj nowy klucz API w AI Studio Google
404 NOT_FOUND Odwołanie do nieistniejącego zasobu (np. usunięty plik, zły identyfikator modelu)
429 RESOURCE_EXHAUSTED Przekroczono limity tokenów. Spróbuj ponownie jutro.
499 CANCELLED Połączenie zostało przerwane przez klienta przed otrzymaniem odpowiedzi z API
503 UNAVAILABLE Serwer jest przeciążony lub trwa przerwa konserwacyjna. Poczekaj chwilę.
504 DEADLINE_EXCEEDED Przetwarzanie zapytania trwało zbyt długo.
